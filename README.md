# Nivin Student Affairs Impact Map

An interactive academic-cycle management dashboard for Student Affairs.

## Features

- Multi-year Fall, Spring and Summer cycle management
- Automatic semester status based on editable dates
- Department service maps and KPI tracking
- Automatic performance status rules
- Full edit mode for services, KPIs and targets
- Evidence tracking and semester closure controls
- Intervention recommendations
- Import and export of editable JSON data
- Browser-local data persistence

## Live Website

Published through GitHub Pages.

## Data privacy

Operational entries are stored in the visitor's browser using local storage. Export a JSON backup regularly. Do not enter confidential student-level data in a public deployment.

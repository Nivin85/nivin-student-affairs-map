# Student Affairs Executive Hub

A public GitHub Pages interface for semester governance, department services, KPI tracking, evidence, closure, and next-semester action planning.

## Key capabilities

- Executive overview by academic year and semester
- Department improvement cycles and service catalogue
- Clickable KPI definitions in every access view
- Department Head, Employee, and Supervisor views
- Limited employee access for actual results and evidence
- In-browser evidence attachments up to 1 MB
- Automatic KPI status and executive-dashboard refresh
- Department closure and following-semester action handover
- Official accreditation and ranking methodology links
- Import and export of the complete governance data package

## Live website

Published through GitHub Pages.

## Important data note

This GitHub Pages edition stores changes in the current browser. Export the governance JSON package to transfer or back up the record. Do not enter confidential student-level data in a public deployment.
